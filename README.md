A single line of quiet, earned pride: after thirty-one years of mopping the same hospital ward at 3 a.m., the night janitor steps back from the gleaming floor and gives it the smallest nod. No trophy, no podium, no graduation — just a small person, a hard job done well for decades, and one small nod that says it all.

The program writes that one line to `/output/entry.txt` for make.fun's "One Line of Earned Pride" bounty.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the entry line to `/output/entry.txt` (creating `/output` if needed).
